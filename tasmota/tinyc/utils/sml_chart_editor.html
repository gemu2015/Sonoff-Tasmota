SML Chart Data Editor

View & edit the raw binary chart files written by the TinyC sml_chart example (/sml_chart.bin — 4-byte little-endian float32, no header). Also reads/writes the #define CHART_CSV tab format.
On-device file (same-origin)
When this page is opened on the device at http://<device>/cedit, these buttons read & write the chart file directly on the device — no manual download/upload. Opened from a local file or another host? Use the drop-zone below instead.
Drop /sml_chart.bin (or .csv) here, or click to choose a file…
Migration path from ottelo's 2_SML_Chart_PV.tas: the Scripter writes 5 lines (481 / 1441 / 31 / 31 / 24). This button splits them into the TinyC port's two bins and downloads both: sml_chart.bin (1965: s4h·s24h·dcon·mcon) + sml_chart_pv.bin (43: dprod·mprod). mcon[24] is split into sml_mcon[12] (→ sml_chart.bin) + sml_mprod[12] (→ sml_chart_pv.bin). Upload BOTH to the device's file manager, then restart the slot.
Layout (arrays in the file, in order)
Defaults match the standard sml_chart.tc. Adjust the counts if your script declares different array sizes — the file is split in this order. The .bin size must equal (total × 4) bytes.
