⚠ macOS denied file reads (TCC sandbox)

The server got Operation not permitted on 0 file read(s). This means the diff list is not reliable — files flagged as "modified" may actually be identical.

Fix: Quit this app and re-launch using Tasmota Merge.command instead of Tasmota Merge.app. The .command file opens in Terminal, which inherits your user permissions and can read files in ~/Desktop / ~/Documents / ~/Downloads.

Why this happens

macOS sandboxes Finder-launched .app bundles. Unsigned apps don't trigger the Files-and-Folders permission prompt and silently fail to read your fork tree if it's in a protected user folder. Terminal.app already has the permission you granted it once for development, so launching from there sidesteps the issue.

Alternative permanent fix: System Settings → Privacy & Security → Full Disk Access → add the .app bundle.
